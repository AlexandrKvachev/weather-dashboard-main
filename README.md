# weather-dashboard
Daily weather application using external API

## About project
Weather application built with React and SCSS.
Allows you to search for any city and get current weather conditions, including a 9-hour forecast and a 7-day forecast.
Also displays additional information such a wind speed, feels like temperature, and high\low temperatures.

**Stack:** React, SCSS, Vite
**API:** OpenWeatherMap, Geoapify, Open-Meteo

## Run guide
```bash 
git clone https://github.com/AlexandrKvachev/weather-dashboard-main.git
cd weather-dashboard-main
npm install
npm run dev
```

You can also view the project [here](https://weather-dashboard-by-alexandr.netlify.app)
